# Disicure Care Pvt. Ltd.

> **"We Cure With Care"**  
> Quality-Driven Pharmaceutical Solutions.

Official B2B website for **Disicure Care Pvt. Ltd.** featuring pharmaceutical product catalogs, third-party manufacturing, PCD franchise opportunities, formulation development, and institutional supply solutions.

## 🚀 Features
- **Responsive Single Page Application (SPA):** Hash-based routing without server dependencies.
- **Product Portfolio & Detailed Views:** Fast interactive search, dosage form filters, and composition information.
- **B2B Service Workflows:** Comprehensive breakdown of third-party manufacturing, PCD franchise, packaging, and supply chains.
- **Direct Lead Generation:** Integrated WhatsApp and multi-field B2B enquiry modals.
- **100% Offline-Ready Assets:** Tailwind, Google Fonts, and medical packshot imagery bundled locally.
